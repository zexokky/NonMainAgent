## 🎯 Что это

**NonMainAI** — это десктопный ИИ-агент, который работает полностью на твоём ПК. Он умеет:

- читать, писать, удалять, перемещать любые файлы;
- писать и запускать Python-скрипты, исправлять ошибки;
- ставить pip-пакеты в виртуальное окружение;
- запускать фоновые процессы (серверы, боты) и следить за логами;
- работать с git (status, diff, commit, log);
- искать в интернете через DuckDuckGo;
- хранить контекст диалога между сессиями.

**Никаких облаков, никаких подписок, никаких утечек данных.** Нейросеть работает локально через [Ollama](https://ollama.com) на твоей видеокарте или процессоре.

## ✨ Возможности

| | Фича | Описание |
|---|---|---|
| 📂 | **Файлы** | Чтение, запись, дописывание, удаление, перемещение. Любые расширения и пути. |
| 🛡 | **Бэкапы** | Перед каждой перезаписью — авто-бэкап. Один клик для отката. |
| 💻 | **Код** | Пишет, проверяет и запускает Python-скрипты. Читает ошибки, исправляет. |
| ⚙️ | **Пакеты** | Автоматически создаёт venv, ставит зависимости, сохраняет requirements.txt. |
| 🚀 | **Процессы** | Запускает серверы и боты в фоне. Читает логи. Умеет останавливать. |
| 🔀 | **Git** | `status`, `diff`, `commit`, `log` — прямо из чата. |
| 🌐 | **Веб-поиск** | Ищет в DuckDuckGo, если нужна свежая информация. |
| 📝 | **Память** | Хранит последние 30 сообщений между сессиями. |
| 🎨 | **Темы** | Тёмная, чёрная, светлая. Выбор сохраняется. |
| 📦 | **Офлайн-режим** | Работает без интернета, если модель уже скачана. |

## 📋 Требования

| Компонент | Минимум | Рекомендуется |
|---|---|---|
| **ОС** | Windows 10 x64 | Windows 11 |
| **Python** | 3.10 | 3.12 |
| **RAM** | 8 ГБ | 16 ГБ |
| **VRAM** | — (работает на CPU) | 6+ ГБ (NVIDIA RTX) |
| **Диск** | 10 ГБ | 20 ГБ SSD |
| **Ollama** | последняя версия | последняя версия |

**Для слабых ПК:** используй модель `qwen2.5:3b` вместо `qwen2.5:7b` — она в 2 раза легче.

## 🚀 Установка

### Вариант 1 — Установщик (рекомендуется)

1. Скачай `NonMainAI_Setup.exe` из [Releases](https://github.com/zexokky/NonMainAI/releases).
2. Запусти. Выбери папку для установки (по умолчанию `C:\AI_Workspace`).
3. Установщик сам поставит:
   - Python (если нет)
   - pip-библиотеки
   - Ollama (если нет)
   - модель `qwen2.5:7b` (4.7 ГБ)
4. После установки на рабочем столе появится ярлык **NonMainAI**.

### Вариант 2 — Вручную из исходников

```bash
# 1. Клонировать репозиторий
git clone https://github.com/zexokky/NonMainAI.git
cd NonMainAI

# 2. Установить Python-зависимости
pip install ollama customtkinter pillow

# 3. Установить Ollama (https://ollama.com/download)

# 4. Скачать модель
ollama pull qwen2.5:7b

# 5. Запустить агента
python agent_gui.py
